Summary

This vignette decomposes clonal HSC transcriptomes into 19 GRPs and identifies associations with clone function. It investigates both post-transplant hematopoiesis (using LARRY barcodes) and native hematopoiesis (using DARLIN barcodes)

Process LARRY

Data preparation

We download a LARRY scRNA-seq dataset (from Scherer et al., 2025), subset to cells annotated as HSC/MPP1, and compute pseudobulks per clone. We also compute clonal properties, such as the output (non-HSC per HSC) and whether the clone has any output.

Process DARLIN

Data preparaiton is conceptually the same as in LARRY, but a bit more involved (click to expand).

First, download the complete DARLIN Data and code.

wget -O DARLIN_public.zip https://zenodo.org/records/11929508/files/DARLIN_public.zip?download=1
unzip DARLIN_public.zip

Second, reproduce the code by the DARLIN authors to create an adata object that contains clone & cell type info. This code is based on a package, COSPAR, that was not trivial to install, I used:

conda create -n cospar-pip -c conda-forge python=3.10 pip
conda activate cospar-pip
pip install "scikit-learn>=1.2" scanpy cospar

And then I had to fix the code in envs/cospar-pip/lib/python3.10/site-packages/cospar/tool/_clone.py to replace some instances of .A by toarray(). Then I prepared an adata object in python that had both clone and transcriptome / cell type annotation info.

  sapply(x, function(y) {
    if (is.na(y) || y == "") return(y)
